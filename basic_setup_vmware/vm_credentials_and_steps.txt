TO Open Terminal(CMD) in VM(Ubuntu) ----> ctrl+alt+T

sudo docker ps ----> shows running images
sudo docker ps -a ---> shows all images(running and stopped)

VIM(use `:` to execute commands)--->
vim <File Path> ----> Opens File in VIM
press i ----> To start Editing
Press Esc ----> to stop editing
paste ----> ctrl + shift + v
:q! – Quit immediately and discard all unsaved changes.
:wq – Save your changes and quit.
:q – Quit only if you haven't made any changes.
:x – Save and quit (only writes to disk if changes exist).

poweroff ---> turn off the machine


sudo -i ----> Switch to root User
exit ---> switch back to non-root user
su - <user name> ----> switch to a non root user

#### SSH Into the Machine
In VM: 
sudo apt update ------------------------> update apt
sudo apt install openssh-server -y --------------> install openssh server
sudo systemctl status ssh ----> check that it's running

ip a ----> Find the ens33 ip address

In Host Machine
ssh <user name>@<IP Address> ----> connect
Eg: ssh ayansau@192.168.154.132

vim <Script_name>.sh ----> to create scripts
